# WERT — frontend

Interface web de um projeto SaaS de gestão, construída com Next.js, React, TypeScript e Tailwind CSS. Esta é uma versão de portfólio revisada a partir do repositório privado de desenvolvimento, com um histórico novo para não publicar arquivos de configuração ou dados antigos.

## Escopo presente no código

- Autenticação, cadastro e áreas administrativas.
- Telas de inventário, produtos e usuários.
- Componentes de interface e formulários.

## Executar

Instale as dependências com `npm install` e inicie com `npm run dev`. Configure `NEXT_PUBLIC_BACKEND_URL` e os demais valores de ambiente exigidos pelos fluxos usados. Nenhuma credencial deve ser colocada no código ou enviada ao repositório.
